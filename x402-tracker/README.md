# x402-tracker — x402 / agent-pay 赛道的「真实收入」追踪器

> 解决的问题：x402 生态**笔数与金额各说各话**（x402.org 首页 30 天 75.41M 笔 / $24.24M；
> x402scan 全历史 20.42M 笔 / 原始金额 1.02e12≈$1.02M）。到底有没有人真的在这一层赚钱？
> 唯一可信的口径是**链上已结算、可归因到具体 listing** 的金额——本脚本每天拉一次并落时间序列。

## 数据源

`https://x402-list.com/api/v1/services?per_page=100&page=N`（公开、无鉴权、9 页×100 条）
许可：**CC-BY-4.0，须署名** —— 输出里保留 `Data: x402-list.com (CC BY 4.0)`。
口径：`assessment.traction.volume_usd_30d` = 该目录**观测到的 facilitator 上已结算 USDC**，
是**下限**（floor）而非估计；`status != measured` 的 listing 记为「未测量」，**不当作 0**。

## 用法

```bash
python3 x402_revenue_track.py                # 默认输出到 ./data
python3 x402_revenue_track.py --out /tmp/d   # 自定义输出目录
```

输出：
- `data/snapshots/<UTC 日期>.json` — 当日全量（summary + 全部 listing 原始记录）
- `data/series.jsonl` — 时间序列，每天一行汇总
- `data/latest.md` — 人类可读摘要

## 结论（写进产品决策，不要拐弯）

1. **不要把 x402 pay-per-call 当收入渠道**：剔除那个游戏结账的离群点，538 家服务 30 天合计
   约 $17.4K，**中位数服务一个月几十美元**。单笔 $0.10 的量级意味着要挣 $100/月需 1,000 次付费调用。
2. **赛道「热」和「赚钱」是两件事**：笔数百万级、金额几万美元级，两个索引方还互相矛盾。
3. **可用的商业信号在「测量层」**：x402-list.com 自己就靠「独立测量 + 付费 verify 档」变现；
   目录里还有 `scvd.store — evidence observatory for the x402 economy`（30 天 $919）。
   → 「独立测量/验证」在这个赛道是被验证过的付费需求，而不是空想。
4. **离群点要单独看**：66.2% 的成交额来自一个游戏结账，说明「人类消费型结账」比「agent 调 API」
   更能出钱——这对定价与选品是关键反证。

## 日更管线（2026-10-11 起）

cron `x402-tracker 每日抓取`（`0 20 * * *`）跑的是 profile 脚本
`~/.hermes/profiles/alpha-scout/scripts/x402_track_wrapper.sh`（**脚本体不进本仓库，避免多份副本漂移**），
它依次执行：

1. `x402_revenue_track.py --out ./data` — 抓全目录快照，产出 `data/snapshots/<日期>.json`、
   `data/series.jsonl`、`data/latest.md`（含头部 1/3/5 家集中度）。
2. `x402_integrity.py` — 「刷量调整」口径：按 `top_buyer_share_30d` 分档，
   把**疑似单一对手方（≥0.8）** 与**买家分散（<0.5）** 分开，产出并覆盖 `data/integrity-latest.md`。
   失败只告警，不拖垮主抓取。

**为什么要第 2 步**：目录口径的成交额会被单一对手方（自成交/合成流量）抬高。
以 2026-10-11 快照为例，毛口径 $410,574 里

| 口径 | 金额 | 占比 |
|---|---|---|
| 买家分散（可信） | $134,635 | 32.8% |
| 疑似单一买家 | $272,976 | 66.4% |

即「市场」三分之二是单一对手方，真实外部需求约 13.5 万/30 天。
引用本数据时**必须同时给出这两个口径**，只用毛口径会高估需求。
